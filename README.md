# Veyra

Versões para Windows e atualizações do aplicativo Veyra.

[Baixar a versão mais recente](https://github.com/josealencar1/veyra-updates/releases/latest)

Baixe **Veyra.exe** nos arquivos da versão. As versões com atualizador avisam quando houver uma atualização e permitem baixar e reiniciar pelo próprio app. Não é necessário login no GitHub.

Feche o Rocket League antes de instalar ou atualizar módulos do jogo. Atualizar o aplicativo preserva seus mods e bibliotecas; reaplique as opções desejadas para levar as alterações ao jogo.

As notas de cada versão indicam mudanças e validações pendentes. Este repositório distribui apenas executáveis e metadados assinados; o código-fonte é mantido separadamente.
